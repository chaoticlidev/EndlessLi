# Contributing to EndlessLi

First off, thank you for checking out EndlessLi!

## Current Contribution Policy

**EndlessLi is currently not accepting external code contributions (Pull Requests).**

This is a solo-developed project, and the codebase is maintained with a specific workflow and architecture. To keep the project stable and maintainable, I am not merging outside code at this time.

However, **bug reports and feature suggestions are incredibly valuable and very welcome!**

## How to Help

### 1. Reporting Bugs

If you find a bug, please open an Issue. To help me fix it quickly, please include:

* **What you expected to happen.**
* **What actually happened.**
* **Steps to reproduce the bug** (if possible).
* **Your OS and app version.**
* *(Optional)* Screenshots or console errors.

### 2. Suggesting Features

If there is a feature you would love to see in EndlessLi, please open an Issue and use the "Feature Request" format. I cannot promise every feature will be implemented, but I read every suggestion.

### 3. Sharing Prompts and Skills

Even though I am not accepting code PRs, EndlessLi is built to be extensible! 

* If you write a great **Skill** (Markdown) or **Script** (Python), you don't need to contribute it to the core repo.
* You can share it in the Discussions tab, or keep it in your own personal library.

## Security

If you discover a security vulnerability, please do **not** open a public issue. Follow the instructions in the [SECURITY.md](SECURITY.md) file to report it privately.

## Thank You

Even if you are just here to use the app, read the docs, or report a typo, thank you for being part of the journey.
